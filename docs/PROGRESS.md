# 개발 진행 현황

마지막 업데이트: 2026-11-12

## 현재까지 구현한 기능

- React, TypeScript, Vite 웹 애플리케이션, 상단 차시 메뉴, 밝은 학습 화면과 어두운 천체 시뮬레이션 영역
- 차시별로 분리한 화면 구조와 물리 계산 모듈
- NASA Goddard Planetary Fact Sheet를 출처로 표시하는 여덟 행성 자료
- 케플러 방정식 기반 타원 궤도 상태 계산, 속력, 공전주기, 정확한 쓸린 면적, 이동 거리 수치 적분
- GitHub Pages용 GitHub Actions 배포 워크플로

## 1차시 최종 점검

케플러 제1법칙 단계형 탐구를 유지하면서 마지막 점검에서 계산과 화면 배치를 확인했습니다.

- 이심률에 따른 장·단반지름과 초점 간격은 `c = ae`, `b = a√(1−e²)` 관계를 사용합니다.
- 태양 초점과 다른 초점은 타원의 중심에서 서로 반대 방향으로 `ae`만큼 떨어져 있습니다. 원에 가까운 궤도에서도 두 점이 겹쳐 보이지 않도록 다른 초점은 점선 테두리 기호로 구분했습니다.
- 긴반지름 표시는 타원의 중심에서 장축 끝까지 이어집니다.
- 근일점·원일점은 `a(1−e)`, `a(1+e)`로 계산되며, 행성 비교 모드에서는 1 AU 기준 비교값임을 안내합니다.
- 실제 행성 선택, 탐구 1~3 답변과 피드백, 단계 이동, 확인을 거치는 초기화 기능을 보존했습니다.
- SVG의 고정 viewBox와 자동 높이를 유지하고 좁은 화면에서 비율을 강제로 늘리던 최소 높이 규칙을 제거했습니다.

## 2차시 구현 상태

PLAN.md의 수업 시간과 순서를 그대로 반영했습니다(도입 5분, 면적 15분, 속도 10분, 행성 자료 15분, 정리 5분).

1. 도입에서 속도 변화에 대한 예상을 고르고 이유를 별도 기록합니다.
2. 이심률을 조절할 수 있는 교육용 예시 타원에서 재생·일시정지·초기화·배속을 조작합니다. 케플러 방정식으로 계산한 12개의 동일 시간 구간이 차례로 누적되며, 학생이 영역을 선택해 경과 시간과 면적을 비교합니다.
3. 전개 1에서 선택한 1번(근일점)·7번(원일점 부근) 구간을 그대로 사용합니다. 같은 시간 동안 이동한 궤도 거리, 위치 순간 속력, 구간 평균 속력을 구분해 비교합니다. 평균 속력은 이동 거리/시간으로 계산하고 두 구간의 같은 Δt를 표시합니다.
4. 여덟 행성의 평균 태양 거리(긴반지름 근삿값)와 공전주기를 일반 눈금에서 비교하고, 내행성·외행성 범위를 바꿔 살펴봅니다. 오른쪽 `P²`-`a³` 그래프도 선형·동일 범위 축으로 표시해 비례 관계를 확인합니다.
5. 세 문장을 케플러 법칙에 연결하고, 다음 차시의 화성 전이 궤도 탐구를 안내합니다.

도입, 면적, 속도, 제3법칙 발견, 정리 기록은 별도 상태로 관리합니다. 모든 시뮬레이션 계산은 SI 단위 물리 모듈을 사용하고 표시 단위 변환은 화면에서 수행합니다. 실측 자료의 반올림과 이상적인 두 천체 모델의 차이를 안내합니다.

면적 탐구는 학생이 시뮬레이션을 먼저 조작하고, 1번·7번 영역을 골라 모양과 수치를 관찰한 다음 답하도록 구성했습니다. 과거의 임의 직사각형 면적 비교는 제거하고 실제 궤도의 부채꼴과 동일 시간 구간 수치로 비교합니다. 궤도의 12개 구간은 시간으로 균등 분할하고, 각 경계 위치는 타원 궤도 물리 모듈의 케플러 방정식 풀이로 구합니다.

2차시의 속력 비교는 같은 궤도와 1번·7번 동일 시간 간격을 사용합니다. 실제 이동 거리는 궤도 속력을 수치 적분하고, 평균 속력은 거리/시간으로 계산합니다. 순간 속력과 평균 속력은 서로 다른 값임을 이름과 설명으로 구분합니다.

1·2차시의 마무리 화면은 같은 `LessonCompletion` UI를 사용합니다. 핵심 정리, 연한 초록색 다음 차시 예고, 완료 표시와 재시작 버튼 배치를 통일했고 완료 후 사이드바의 중복 재시작 버튼은 숨깁니다. 다음 차시 예고 문구는 각각 요청한 문구로 맞췄습니다.

### 초보 학습자를 위한 1·2차시 시각화 개선

- 2차시 전개 1에서 선택한 두 영역은 궤도에서 밝게 남고 나머지 영역은 흐리게 표시합니다. 선택 즉시 실제 부채꼴 비교 화면과 같은 축척의 면적 막대그래프가 표시되어 학생이 먼저 관찰한 뒤 답합니다.
- 비교용 SVG는 두 영역에서 같은 viewBox와 축척을 사용하고, 초점 위치만 이동합니다. 확대 시 영역을 늘이거나 모양을 변형하지 않습니다. 번호·위치·시간(약 30일)·면적(0.205 AU²)을 기본 표시하고 정확한 시간·면적은 펼침 영역에서 확인할 수 있습니다. 제2법칙의 명시적 정리와 피드백은 답변 뒤에만 표시합니다.
- 전개 2에서는 같은 궤도와 1번·7번 구간의 색 경로를 먼저 관찰합니다. 응답 전에는 이동 거리와 평균 속력 수치를 감추고, 답변 뒤 거리·구간 평균 속력과 `평균 속력 = 이동 거리 ÷ 걸린 시간`을 보여 줍니다. 순간 속력은 세부 정보로 분리합니다.
- 1차시 궤도 그림에 근일점·원일점 이름을 동적으로 배치했습니다. 이심률에 따른 단축 길이 변화에 맞춰 타원 바깥에 놓이며 2차시와 같은 크기·색의 글씨를 씁니다.

### 2차시 제2법칙 면적 보존 애니메이션

- 기존 12개 동일 시간 영역과 두 영역 선택 기능을 유지합니다. 선택 직후 같은 축척의 실제 부채꼴을 보여 주고, `면적 비교 애니메이션`을 실행하면 각 부채꼴을 8개 시간 조각으로 나누어 순서대로 채웁니다.
- 조각 경계는 케플러 방정식으로 구한 실제 궤도 위치를 사용합니다. 각 조각과 누적 표시값은 물리 모듈의 `sweptAreaBetweenTimes` 계산에서 얻으며, 같은 시간 조각별 면적을 두 행의 공통 축척 막대로 함께 누적합니다. 도형 확대·축소나 면적 임의 조정은 하지 않습니다.
- 재생·일시정지·계속 재생·다시 보기와 느리게/보통/빠르게 속도 조절을 추가했습니다. 선택한 영역을 바꾸면 그림·누적 애니메이션·응답 상태가 다시 초기화됩니다. 애니메이션이 끝난 뒤 질문이 활성화되고 응답 뒤에 제2법칙 설명이 표시됩니다.
- 테스트에 여러 이심률과 궤도 위치에서 8개 조각 면적의 합이 원래 영역 면적과 같고 각 시간 조각의 면적도 같음을 확인하는 검증을 추가했습니다.

### 2차시 전개 2 속력 비교 시각화

- 전개 2에서는 전개 1의 부채꼴 면적 비교 패널과 12개 색 영역을 숨기고 타원 궤도만 배경으로 남깁니다. 근일점 구간은 청록색, 원일점 구간은 주황색의 두꺼운 궤도 호로 표시하고 각 호의 시작점과 끝점을 기호로 구분합니다.
- 재생하면 근일점과 원일점에서 출발한 행성 표시가 동일한 진행률과 동일한 시간 간격으로 함께 이동합니다. 화면의 두 경로는 타원 위의 실제 궤도 호이며, 비교가 끝나면 완성 경로를 계속 보여 줍니다.
- 두 구간의 호 길이와 평균 속력은 학생 응답 뒤에 공개합니다. 거리 계산은 동일한 물리 시간 구간에서 `distanceTraveledBetweenTimes`로 구한 궤도상의 이동 거리이고, 평균 속력은 거리/시간입니다. 태양으로부터의 거리 및 순간 속력과 구분했습니다.
- 전개 1에서 선택한 교육용 이심률·궤도 설정을 이어 쓰고, 전개 2 진입 시 비교 애니메이션만 같은 시간 간격의 0부터 시작합니다. 기존 12개 영역 기능과 면적 비교 단계는 유지했습니다.

## 검증 결과

- `npm test`: 16개 물리 자동 테스트 통과. 케플러 방정식 상태, 좌표와 거리 일치, 원·타원 이심률에서 12개 동일시간 영역 및 시각화용 8개 조각의 면적 보존, 근·원일점 이동 거리 차이, 평균 속력=거리/시간, 제3법칙 비율과 행성 자료를 점검합니다.
- `npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 브라우저에서 2차시 도입 → 면적 비교 → 속도 비교 → 실제 행성 자료 → 정리와 완료 화면까지 진행했습니다. 재생으로 12개 영역이 한 바퀴 순서대로 누적되고, 1번·7번 영역을 선택할 수 있으며 두 영역의 넓이는 각각 0.20541 AU², 차이는 약 `1.94×10⁻¹⁶ AU²`임을 확인했습니다.
- 이번 개선 확인에서는 두 영역 선택 직후 비교 그림·면적 막대·값이 표시되고, 답변 뒤에 제2법칙 설명이 나타나는 순서를 확인했습니다. 잘못된 값은 `정확한 계산값 보기`에서 확인할 수 있습니다.
- 최신 면적 비교 애니메이션은 브라우저에서 1번·7번 실제 부채꼴의 8개 조각 채움, 누적 막대의 같은 수치 진행, 완료 후 질문 활성화, 답변 피드백, 다른 영역 선택 시 진행/응답 초기화를 확인했습니다. 이심률 0.62에서 두 완성 면적은 각각 0.205408 AU²였습니다.
- 전개 2에서는 부채꼴 비교가 사라지고 궤도 호·출발/도착 기호·동시 행성 표시만 남는 것을 확인했습니다. 두 행성의 같은 시간 운동이 끝나면 예상 질문이 열리며, 응답 뒤 근일점 호 136.2백만 km·원일점 호 38.6백만 km와 평균 속력 51.8·14.7 km/s가 표시됩니다. 계산값은 각각 실제 호 길이/동일한 약 30.438일과 일치합니다.
- 브라우저에서 1차시 세 탐구와 정리까지 완료하고 초기화 후 첫 단계·개념 학습 모드·기본 이심률 0.35를 확인했습니다.
- 새 2차시 궤도는 SVG viewBox의 가로·세로 비율을 유지하고 CSS에서 폭에 맞춰 자동 축소하도록 구성했습니다. 좁은 약 580px 브라우저 폭과 데스크톱 화면에서 영역·라벨 및 비교 패널을 시각 확인했습니다.
- 브라우저 점검 중 이동 거리 표시의 변환 단위 오류를 발견해 백만 km 단위로 수정했습니다.
- 속력 비교에서 같은 구간 시간은 30.438일이며, 상세 이동 거리는 근일점 부근 136.170백만 km와 원일점 부근 38.601백만 km입니다. 기본 화면은 136.2 / 38.6백만 km, 평균 속력은 51.8 / 14.7 km/s로 간략히 표시합니다. 세부 값은 정확한 계산값 펼침 영역에서 확인할 수 있습니다.
- 제3법칙 그래프의 선형 눈금, 내행성/외행성 필터, `P²=a³` 기준선 및 두 단계의 답변 피드백을 확인했습니다. 완료 화면의 재시작 버튼은 1개이며 사이드바에 활동 시간 목록이 없습니다.
- 1차시와 2차시의 공유 마무리 화면에서 핵심 내용·초록색 다음 차시 안내·완료 표시·재시작 버튼 구성을 확인했습니다.

## 남아 있는 작업

- 실제 수업 사용자 피드백을 반영합니다.
- UI 단계 전환, 답변 피드백, 재시작 확인/초기화에 대한 자동 통합 테스트를 추가하면 회귀를 더 잘 막을 수 있습니다. 현재 자동 테스트는 물리 모듈 중심입니다.
- 1·2차시의 답변, 관찰 기록, 피드백 판정, 완료 단계, 마지막 차시·단계와 주요 시뮬레이션 설정은 브라우저 `localStorage`에 자동 저장됩니다. 3·4차시 콘텐츠에도 같은 차시별 저장 도구와 진행 메뉴를 재사용합니다.
- 3차시 호만 전이 궤도와 4차시 실제 탐사 임무 비교는 아직 구현하지 않았습니다.

### 공통 진행 단계 및 학습 상태 저장

- 1·2차시 진행 표시를 공통 `LessonStepNavigation`으로 통합했습니다. 현재 단계, 완료한 단계, 이미 도달한 단계는 구분해 표시하고, 도달 전 단계는 비활성화합니다. 3·4차시에서도 단계 수와 이름을 전달해 재사용할 수 있습니다.
- 다음 단계로 진행할 때 완료 단계와 최고 도달 단계를 기록합니다. 이전 단계로 이동해도 답변, 관찰 기록, 피드백 상태 및 시뮬레이션 설정은 유지됩니다. 답을 바꾸면 현재 선택에 맞춰 피드백을 다시 계산합니다.
- 저장 데이터는 `kepler-mars-learning:v1:lesson-1:*`, `lesson-2:*`처럼 차시별로 구분하고, 마지막 선택 차시는 별도 앱 키로 저장합니다. 새로고침 또는 브라우저 재시작 후에도 이어서 열리며, 애니메이션은 자동 재생하지 않습니다.
- 저장 JSON이 손상되었거나 브라우저 저장소를 사용할 수 없는 경우 기본값으로 시작합니다. '처음부터 다시하기'는 확인 뒤 현재 차시의 저장 항목만 삭제하고, 시뮬레이션 개별 초기화는 전체 학습 상태를 지우지 않습니다.
- 2차시 상단의 수업 시간 배분은 학생 화면에서만 제거했습니다. `PLAN.md`의 수업 시간과 활동 순서는 유지했습니다.
- 2차시 면적 비교 완료 상태가 새로고침 뒤 복원될 때 비교 패널이 이를 미완료로 덮어쓰지 않도록 수정했습니다.

### 1차시 단계별 시뮬레이션 모드 복원

- 저장된 진행 단계에서 시뮬레이션 모드를 계산하도록 변경했습니다. 타원 탐구(0단계)와 초점 관찰(1단계)은 이심률 슬라이더를, 실제 행성 비교(2단계)와 정리(3단계)는 행성 선택 도구를 사용합니다. 이전 단계로 이동하거나 새로고침해도 저장된 단계에 맞는 도구가 바로 표시됩니다.
- 자유 조절 이심률, 초점 관찰용 이심률(기본값 0.50), 실제 행성 선택을 별도 저장값으로 분리했습니다. 각 단계에서 다른 설정을 바꾸어도 나머지 두 값은 유지됩니다. 전체 초기화는 세 설정을 기본값으로 되돌립니다.
- `lessonOneSimulationState`를 분리하고 0~3단계에서 모드와 이심률 설정이 올바르게 선택되는 자동 회귀 테스트를 추가했습니다. 물리 계산 모듈과 2차시 기능은 변경하지 않았습니다.

이번 작업의 UI 확인에서는 두 차시 모두 공통 진행 메뉴가 표시되고, 2차시 시간 배분 안내가 빠진 것을 확인했습니다. 답변 작성부터 단계 이동, 새로고침 복원, 차시별 초기화까지 연결한 통합 브라우저 점검은 별도 보완이 필요합니다.

## 실행 방법

```bash
npm install
npm run dev
```

프로덕션 빌드와 자동 테스트:

```bash
npm run build
npm test
```

빌드 결과를 로컬에서 확인하려면 `npm run preview`를 실행합니다. 저장소는 기존 GitHub 원격에 연결되어 있으며, 이번 작업의 변경 사항은 로컬 커밋만 하고 GitHub에는 push하지 않습니다.
