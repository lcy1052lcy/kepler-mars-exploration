# 개발 진행 현황

마지막 업데이트: 2026-11-12

## 현재까지 구현한 기능

- React, TypeScript, Vite 기반 웹 애플리케이션과 GitHub Pages용 GitHub Actions 배포 워크플로
- 상단 차시 메뉴와 밝은 학습 화면, 어두운 궤도 관측 영역을 갖춘 공통 UI
- 학생이 관찰하고 응답하는 단계형 수업 화면 및 단계별 답변·관찰 기록
- NASA Goddard Planetary Fact Sheet의 지구 대비 이심률 비율을 바탕으로 환산한 여덟 행성의 대표 이심률과 출처 링크
- UI와 독립된 물리 모듈: SI 단위 상수, 타원 기하, 근일점·원일점 거리, 케플러 방정식, 궤도 주기·상태 계산
- 물리 함수 자동 테스트 7개

## 1차시 시뮬레이션 완성 상태

1차시 케플러 제1법칙 탐구의 핵심 흐름은 구현되어 있습니다.

1. 이심률 슬라이더로 원에서 타원까지 궤도 모양을 조절하고 변화를 관찰합니다.
2. 이심률 0.50의 궤도에서 중심·두 초점을 비교하고 태양 위치를 선택한 뒤, 낮은 이심률에서 초점 간격이 줄어드는 모습도 확인합니다.
3. 실제 행성을 선택해 대표 이심률을 비교하고, 가장 이심률이 큰 행성과 궤도 모양에 대해 답합니다.
4. 관찰을 케플러 제1법칙으로 정리합니다.

시각화는 동일 비율의 SVG 좌표계를 사용합니다. 태양은 타원의 한 초점, 다른 초점과 중심은 타원 기하의 실제 계산 좌표에 둡니다. 긴반지름은 중심에서 장축 끝점까지 청록색으로 표시하고, 근일점·원일점·중심·초점은 도형 안에 글자를 겹쳐 쓰지 않고 범례로 설명합니다. 근일점 거리, 원일점 거리, 이심률은 궤도 아래에 표시합니다. 실제 행성 비교에서는 화면의 긴반지름을 1 AU로 정규화하며, 표시된 거리는 비교용 계산값이지 각 행성의 실제 태양 거리와 같지 않다고 안내합니다.

탐구 단계별로 기록과 응답 상태를 분리했습니다. 재시작은 확인 후 첫 단계, 개념 학습 모드, 기본 이심률로 돌아가며 응답과 기록을 초기화합니다.

## 남아 있는 수정·점검 사항

- 현재 자동 테스트는 물리 계산 중심입니다. 다음 단계에서 차시 이동, 답변 피드백, 단계 전환, 재시작 확인/초기화의 UI 통합 테스트를 추가하면 회귀를 더 잘 막을 수 있습니다.
- 브라우저에서 네 단계 완료까지는 확인했습니다. 마지막 재시작 확인창을 수락한 직후 브라우저 자동화 연결이 시간 초과되어 초기화된 화면의 재표시까지는 확인하지 못했습니다. 다음 점검 때 확인창 수락 후 첫 단계·기본 이심률·기록 삭제 상태를 다시 확인합니다.
- 행성 이심률은 교육용 대표값입니다. 출처의 기준 자료와 반올림 방식은 `src/content/planetEccentricities.ts`에 기록되어 있습니다. 정밀한 날짜별 궤도요소가 필요한 차시에서는 epoch와 좌표계를 명시한 JPL 자료로 별도 모델링합니다.
- 기록은 현재 브라우저 화면의 React 상태로만 유지되며 새로고침 후 저장되지 않습니다. 학생 기록을 저장할 필요가 생기면 개인정보와 수업 운영 조건을 검토한 후 설계합니다.
- 2~4차시 시뮬레이션은 아직 구현하지 않았습니다.

## 다음 개발 목표: 2차시 케플러 제2·3법칙

### 탐구 A — 같은 시간, 같은 면적

- 타원 궤도에서 근일점과 원일점 구간을 선택해 같은 시간 간격의 태양-행성 면적을 비교합니다.
- 기존 `stateAtTime`과 궤도 기하 계산을 활용해 위치를 계산하고, 면적은 같은 중심 천체 기준의 삼각형/부채꼴 면적으로 일관되게 구합니다.
- 학생은 가까운 곳과 먼 곳에서 속력 및 이동 거리가 어떻게 달라지는지 예측한 뒤 시뮬레이션 결과를 설명합니다.
- 면적 속도 일정은 두 천체 중심력 모델의 가정 아래서 표현하고, 시간 간격·각도 처리 및 수치 오차를 자동 테스트합니다.

### 탐구 B — 궤도 크기와 공전주기

- 행성의 긴반지름 `a`와 공전주기 `T` 자료를 표와 그래프로 비교합니다.
- `T²/a³`의 값이 동일한 중심 천체 기준에서 거의 일정함을 확인하도록 합니다.
- 단위 변환을 명시하고, 태양 질량 기준 SI 물리 모듈 결과와 출처 자료를 교차 확인합니다.
- 이상적인 두 천체 계산과 실제 행성 자료의 차이를 반올림·섭동 등의 모델 한계와 함께 안내합니다.

## 실행 방법

```bash
npm install
npm run dev
```

프로덕션 빌드와 자동 테스트:

```bash
npm run build
npm test
```

빌드 결과를 로컬에서 확인하려면 `npm run preview`를 실행합니다. GitHub Pages 배포는 원격 저장소를 만들고 연결한 뒤 GitHub 저장소 Settings에서 Pages 배포 소스로 GitHub Actions를 선택하는 단계가 필요합니다. 현재 프로젝트는 원격에 연결하거나 업로드하지 않았습니다.
